# bubbaloop-dash Phase 1.2a (Decode + Job Runner) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatic frame extraction from uploaded videos. A POST `/api/videos/{id}/complete` auto-enqueues a job; the runner decodes the source mp4 with PyAV at `SAMPLE_FPS=1.0`, writes downscaled JPEGs to `videos/<id>/streams/rgb/`, and transitions the video through `queued → indexing → done`. Library renders new badges + a Retry button when a job is `interrupted` (server crash mid-decode).

**Architecture:** Single asyncio `indexing_loop` task in the FastAPI lifespan polls SQLite for queued jobs via `claim_next_indexing_job` (BEGIN IMMEDIATE for atomicity). On claim, it dispatches the blocking PyAV decoder to the default `ThreadPoolExecutor` via `loop.run_in_executor` so the event loop stays free for HTTP + sweeper + Zenoh. Decoder samples every Nth source frame (N = `source_fps / SAMPLE_FPS`), downscales to `JPG_MAX_DIM=1280`, writes JPEG q=90 to disk. Progress is published to `bubbaloop-dash/jobs/<id>/progress` over Zenoh every `INDEXING_PROGRESS_INTERVAL_FRAMES=10`. Sweeper extension `recover_interrupted_at_startup` runs ONCE at lifespan start, marking any `status='indexing'` videos as `interrupted`.

**Tech Stack:**
- Backend: Python 3.11, FastAPI, sqlite3 (WAL), asyncio, `av` (PyAV ≥13.0,<14.0), `pillow>=10.0,<12.0`, `numpy>=1.26,<3.0` (transitive via PyAV but pinned), `structlog`, pytest.
- Frontend: React 18 + TypeScript + Vite (existing). No new npm deps.
- New system dep: `ffmpeg` available on PATH at test time for fixture generation (skip-decorated tests if absent).

**Repository:** `/home/nvidia/bubbaloop-dash/`, branch `feat/phase-1.2a-decode`.

**Out of scope (Phase 1.2b or later):** open_clip / torch / lancedb / search REST endpoint / GPU / multi-stream / keyframe seeking / resumable indexing / per-upload SAMPLE_FPS override / cancel-running-indexer / frontend Zenoh subscription.

Replace the `open` classmethod body. The schema.sql now contains an ALTER TABLE that fails on re-open; we run that statement separately wrapped in try/except.

```python
    @classmethod
    def open(cls, path: Path) -> "Db":
        path.parent.mkdir(parents=True, exist_ok=True)
        conn = sqlite3.connect(path, check_same_thread=False, isolation_level=None)
        conn.execute("PRAGMA journal_mode = WAL")
        conn.execute("PRAGMA foreign_keys = ON")
        conn.execute("PRAGMA busy_timeout = 5000")
        # Read the schema file. It contains CREATE TABLE IF NOT EXISTS (idempotent)
        # plus ALTER TABLE ADD COLUMN which is NOT idempotent — guard it.
        sql = _SCHEMA_PATH.read_text()
        for stmt in [s.strip() for s in sql.split(";") if s.strip()]:
            try:
                conn.execute(stmt)
            except sqlite3.OperationalError as exc:
                # "duplicate column name" — ALTER TABLE already applied. Ignore.
                if "duplicate column" not in str(exc):
                    raise
        # Migrate 1.1-era 'ready' rows to 'queued'.
        import time
        now_ms = int(time.time() * 1000)
        conn.execute(
            "UPDATE videos SET status='queued', updated_at=? WHERE status='ready'",
            (now_ms,),
        )
        return cls(conn)
```

```python
    def mark_queued(self, video_id: str, now_ms: int) -> None:
        """Phase 1.1's /complete handler used mark_ready; Phase 1.2a uses this.
        Atomic: videos.status='queued' + jobs.status='queued'."""
        self._conn.execute("BEGIN")
        try:
            self._conn.execute(
                "UPDATE videos SET status='queued', updated_at=?, completed_at=? WHERE id=?",
                (now_ms, now_ms, video_id),
            )
            self._conn.execute(
                "UPDATE jobs SET status='queued', progress_pct=100, finished_at=? "
                "WHERE video_id=? AND kind='upload'",
                (now_ms, video_id),
            )
            self._conn.execute("COMMIT")
        except Exception:
            self._conn.execute("ROLLBACK")
            raise
```

Note: `jobs.progress_pct=100, finished_at=?` reflects that the UPLOAD job is done — the indexing job (kind='indexing', if we add it later) is separate. For 1.2a we keep one job row per video (kind='upload') and just transition its status through the indexing states. Phase 1.2b may add a second job row for the embedding phase; that's a future decision.

```python
        """BEGIN IMMEDIATE; pick next queued upload job; transition to indexing.
        Returns IndexerJob with job_id + video_id + ext, or None if no queued."""
        self._conn.execute("BEGIN IMMEDIATE")
        try:
            row = self._conn.execute(
                "SELECT j.id, j.video_id, v.ext "
                "FROM jobs j JOIN videos v ON v.id = j.video_id "
                "WHERE j.kind='upload' AND v.status='queued' "
                "ORDER BY j.started_at ASC LIMIT 1"
            ).fetchone()
            if row is None:
                self._conn.execute("COMMIT")
                return None
            job_id, video_id, ext = row
            self._conn.execute(
                "UPDATE videos SET status='indexing', updated_at=? WHERE id=?",
                (now_ms, video_id),
            )
            self._conn.execute(

                (job_id,),

            self._conn.execute("COMMIT")
            return IndexerJob(job_id=job_id, video_id=video_id, ext=ext)
```

```python
"""Synchronous PyAV-based frame extractor.

Run inside a ThreadPoolExecutor via asyncio.run_in_executor — libavcodec
releases the GIL during decode so the event loop stays free."""
from collections.abc import Callable
from pathlib import Path

import av
import numpy as np
from PIL import Image

from dash.config import Settings


class PyAVDecoder:
    def __init__(self, settings: Settings) -> None:
        self._sample_fps = settings.sample_fps
        self._jpg_quality = settings.jpg_quality
        self._jpg_max_dim = settings.jpg_max_dim
        self._progress_interval = settings.indexing_progress_interval_frames

    def extract(
        self,
        source_path: Path,
        out_dir: Path,
        progress_cb: Callable[[int, int], None],
    ) -> int:
        """Decode source, sample at sample_fps, write JPEGs. Returns frame count.
        progress_cb(frame_idx, total_estimated) every progress_interval frames."""
        out_dir.mkdir(parents=True, exist_ok=True)
        container = av.open(str(source_path))
        try:
            stream = container.streams.video[0]
            source_fps = float(stream.average_rate) if stream.average_rate else 30.0
            duration_s = (
                float(container.duration / av.time_base)
                if container.duration is not None
                else None
            )
            sample_interval = max(1, round(source_fps / self._sample_fps))
            total_est = (
                int(duration_s * self._sample_fps) if duration_s is not None else 0
            )

            frame_idx = 0
            decoded_count = 0
            for packet in container.demux(stream):
                for frame in packet.decode():
                    if decoded_count % sample_interval == 0:
                        img = frame.to_ndarray(format="rgb24")
                        img = _maybe_downscale(img, self._jpg_max_dim)
                        _write_jpeg(out_dir / f"{frame_idx:06d}.jpg", img, self._jpg_quality)
                        frame_idx += 1
                        if frame_idx % self._progress_interval == 0:
                            progress_cb(frame_idx, total_est)
                    decoded_count += 1
        finally:
            container.close()
        progress_cb(frame_idx, frame_idx)
        return frame_idx


def _maybe_downscale(img: np.ndarray, max_dim: int) -> np.ndarray:
    """Resize so the longest dimension ≤ max_dim, preserving aspect ratio."""
    h, w = img.shape[:2]
    if max(h, w) <= max_dim:
        return img
    if w >= h:
        new_w = max_dim
        new_h = round(h * (max_dim / w))
    else:
        new_h = max_dim
        new_w = round(w * (max_dim / h))
    return np.asarray(
        Image.fromarray(img).resize((new_w, new_h), Image.BILINEAR)
    )


def _write_jpeg(path: Path, img: np.ndarray, quality: int) -> None:
    Image.fromarray(img).save(path, format="JPEG", quality=quality)
```

```python
"""Indexing job runner.

A single asyncio.Task in the FastAPI lifespan polls SQLite for queued
upload-jobs via Db.claim_next_indexing_job (atomic). For each job, it
dispatches the blocking PyAV decoder to the default ThreadPoolExecutor
via asyncio.run_in_executor — libavcodec releases the GIL during decode
so the event loop stays free for HTTP + sweeper + Zenoh subscribers.

Progress is published to bubbaloop-dash/jobs/<job_id>/progress on Zenoh
every INDEXING_PROGRESS_INTERVAL_FRAMES decoded sampled frames + once
at start + once at end."""
import asyncio
import json
import time
from typing import Any

from dash.config import Settings
from dash.db.sqlite import Db, IndexerJob
from dash.decode.pyav_decoder import PyAVDecoder
from dash.logging import get_logger
from dash.storage.base import Storage
from dash.zenoh_proxy.session import ZenohSession

_log = get_logger("dash.jobs.indexer")


def _now_ms() -> int:
    return int(time.time() * 1000)


class Indexer:
    """Synchronous frame extractor wrapper. Run in threadpool executor."""

    def __init__(self, storage: Storage, settings: Settings) -> None:
        self._storage = storage
        self._settings = settings
        self._decoder = PyAVDecoder(settings)

    def run(self, job: IndexerJob, progress_cb: Any) -> int:
        """Run decode + write frames. Returns frame count.
        Source: "videos/{video_id}/source.{ext}"
        Out:    "videos/{video_id}/streams/rgb/{frame_idx:06d}.jpg" """
        # Storage.url_for + Path resolution: we go via the storage root directly.
        from pathlib import Path
        data_root = Path(self._storage._root) if hasattr(self._storage, "_root") else None
        if data_root is None:
            raise RuntimeError("storage backend lacks a filesystem root")
        source = data_root / "videos" / job.video_id / f"source.{job.ext}"
        out_dir = data_root / "videos" / job.video_id / "streams" / "rgb"
        return self._decoder.extract(source, out_dir, progress_cb)


def publish_progress(
    zsess: ZenohSession,
    job_id: str,
    pct: int,
    frame_idx: int,
    total: int,
) -> None:
    """Fire-and-forget Zenoh publish. Called from runner thread."""
    if zsess.status() != "ok":
        return
    key = f"bubbaloop-dash/jobs/{job_id}/progress"
    payload = json.dumps(
        {"pct": pct, "stage": "decoding", "frame_idx": frame_idx, "total_estimated": total},
    ).encode("utf-8")
    try:
        zsess.session().put(key, payload, encoding="application/json")
    except Exception as exc:  # noqa: BLE001
        _log.warning("zenoh.progress_publish_failed", job_id=job_id, error=str(exc))


async def indexing_loop(
    db: Db,
    storage: Storage,
    settings: Settings,
    zsess: ZenohSession,
    poll_interval_s: float = 2.0,
) -> None:
    """Long-running coroutine. Cancelled cleanly on lifespan shutdown."""
    indexer = Indexer(storage, settings)
    while True:
        try:
            await asyncio.sleep(poll_interval_s)
        except asyncio.CancelledError:
            _log.info("indexer.cancelled")
            raise
        try:
            job = db.claim_next_indexing_job(now_ms=_now_ms())
        except Exception:
            _log.exception("indexer.claim_failed")
            continue
        if job is None:
            continue
        await _run_one(db, indexer, job, zsess)


async def _run_one(db: Db, indexer: Indexer, job: IndexerJob, zsess: ZenohSession) -> None:
    loop = asyncio.get_running_loop()

    def progress_cb(frame_idx: int, total: int) -> None:
        pct = int(100 * frame_idx / max(total, 1)) if total > 0 else 0
        try:
            db.update_indexing_progress(job.job_id, pct=pct, now_ms=_now_ms())
        except Exception:  # noqa: BLE001
            _log.exception("indexer.progress_db_update_failed")
        publish_progress(zsess, job.job_id, pct, frame_idx, total)

    try:
        _log.info("indexer.start", job_id=job.job_id, video_id=job.video_id)
        frame_count = await loop.run_in_executor(None, indexer.run, job, progress_cb)
        db.mark_indexed(job.video_id, indexed_frame_count=frame_count, now_ms=_now_ms())
        _log.info("indexer.done", job_id=job.job_id, frame_count=frame_count)
    except Exception as exc:  # noqa: BLE001
        db.mark_index_error(job.video_id, reason=str(exc), now_ms=_now_ms())
        _log.exception("indexer.failed", job_id=job.job_id)
```

Note on `data_root = Path(self._storage._root)`: the indexer needs the absolute path for PyAV's `av.open(...)`. The `Storage` Protocol doesn't currently expose `root()`. We reach in to the FilesystemStorage's private `_root`. For S3Storage in the future, this won't work — but Phase 2's S3 swap will need a different strategy (download to local temp before decoding). For 1.2a + FilesystemStorage, the leak is acceptable.

A cleaner alternative: add a `root_path() -> Path | None` method to Storage. Optional improvement; not blocking 1.2a.

```python
        app.state.indexer_task = indexer_task
        try:
            yield
        finally:
            indexer_task.cancel()
            try:
                await indexer_task
            except asyncio.CancelledError:
                pass
            sweeper_task.cancel()
            try:
                await sweeper_task
            except asyncio.CancelledError:
                pass
            await zsess.stop()
            db.close()

        title="bubbaloop-dash",
```

```python
"""End-to-end: upload a real (tiny) mp4, wait for indexing, verify frames on disk."""
import asyncio
from pathlib import Path

import pytest
from fastapi.testclient import TestClient


@pytest.mark.e2e
def test_full_upload_to_indexing(
    client: TestClient, settings, fixture_video_path: Path,
) -> None:
    headers = {"Authorization": f"Bearer {settings.dashboard_token}"}

    # 1. Create upload session.
    src_size = fixture_video_path.stat().st_size
    r = client.post(
        "/api/videos",
        json={"filename": "e2e.mp4", "size_bytes": src_size, "content_type": "video/mp4"},
        headers=headers,
    )
    assert r.status_code == 200
    info = r.json()

    # 2. PUT all chunks. fixture is small (< 1 chunk).
    src = fixture_video_path.read_bytes()
    chunk_size = info["chunk_size"]
    total = info["total_chunks"]
    for n in range(total):
        start = n * chunk_size
        end = min(start + chunk_size, src_size)
        r = client.put(
            f"/api/videos/{info['video_id']}/chunks/{n}",
            content=src[start:end],
            headers=headers,
        )
        assert r.status_code == 204

    # 3. Complete.
    r = client.post(f"/api/videos/{info['video_id']}/complete", json={}, headers=headers)
    assert r.status_code == 200
    assert r.json()["status"] == "queued"

    # 4. Wait up to 30s for indexing to finish.
    import time
    deadline = time.time() + 30
    last_status = None
    while time.time() < deadline:
        v = client.get(f"/api/videos/{info['video_id']}", headers=headers).json()
        last_status = v["status"]
        if last_status in ("done", "error"):
            break
        time.sleep(0.5)
    assert last_status == "done", f"final status was {last_status}"
    detail = client.get(f"/api/videos/{info['video_id']}", headers=headers).json()
    assert detail["indexed_frame_count"] == 2  # 2-second test video at 1 fps

    # 5. Verify JPEGs on disk.
    frames_dir = settings.data_dir / "videos" / info["video_id"] / "streams" / "rgb"
    assert frames_dir.exists()
    jpgs = sorted(frames_dir.iterdir())
    assert len(jpgs) == 2
    assert jpgs[0].name == "000000.jpg"
    assert jpgs[1].name == "000001.jpg"
```
